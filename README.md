# hanage-html
鼻毛を抜くゲームです。ソースをエディター　メモ帳、テキスト加工できるツールににコピーし、適当に名前をつけ。HTML拡張子で保存し、エクスプローラーやブラウザで指定すれば動きます。
鼻毛が見えてると判ったら？指で摘んで引っこ抜かないと？ハナゲー　と歩くと？指摘される　あなたは、マウスをクリックして鼻毛を抜かないといけない！　そんなゲームを作って、さらにスマホ対応で、音もつけてと指示してできた結果がこれです。
